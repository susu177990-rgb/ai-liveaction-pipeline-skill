# Contact Map Guide

`contact_map` is a first-class layer.

Use it to mark:

- foot-ground contacts
- hand-wall or hand-table contacts
- body-seat or body-table contacts
- prop touch or prop support points

## Contract

- one structured note or image layer per frame
- explicit coordinate or region description when possible
- path stored in the frame manifest

If contact logic is unclear, stop claiming the frame is ready for fusion.
